# 发布副本说明

此目录是独立源码快照，不含原开发仓库的 Git 历史。

保留：MCP 服务、审计模块、fake CLI 回归测试、通用协议文档、报告生成脚本。
排除：真实会话、消息和任务 ID，真实模型回复，用量与经验报告，主机迁移证据，个人历史记录、原始日志、会话数据库、密钥文件及旧 Skill。

发布副本的适配：
- CLI 默认候选路径使用 ProgramFiles；实际安装可用 ZCODE_BRIDGE_CLI 配置。
- 缺失目录测试使用临时目录。
- 主机定位测试使用临时配置，不依赖开发者主机。
- .gitignore 排除运行数据及自动报告。

示例路径和测试中的 sess_fake 等标识是通用示例或合成测试数据，不是实际会话。
运行服务后仍会产生本地数据；每次发布前应检查 Git 暂存区。没有历史数据不意味着之后生成的报告可以直接公开。
公开仓库仅发布此脱敏源码快照；原开发仓库和运行数据不随之上传。
